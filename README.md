## 技术栈

- **静态网站生成器**：Hexo 8.1.2
- **运行环境**：Node.js 20
- **主题**：AnZhiYu、Butterfly、Landscape
- **模板与内容渲染**：EJS、Pug、Marked、Stylus
- **站点扩展**：文章归档、分类、标签、搜索数据库生成器
- **持续集成与部署**：GitHub Actions 自动构建，通过 SSH 部署到服务器

## 本地开发

```bash
npm install
npm run server
```

生成静态文件：

```bash
npm run build
```
