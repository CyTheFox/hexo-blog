# 计算方法

先把数据 $M(x)$ ，和算法需要的 `生成多项式` $G(X)$ 的二进制数据看作 $\text{GF}(2)$ 上的多项式。

> $\text{GF}(2) = \mathbb{Z}/2\mathbb{Z}$ 在二进制上定义的域，可以看作布尔代数。其中的元素为 $\{0, 1\}$ ，加法运算为异或 `^` ，乘法运算为与 `&` 。一个显然的事实是， $\text{GF}(2)$ 中每个元素（1或0）的逆元是它自身，0为加法单位元。

> 高位优先表示：高位在左，低位在右；低位优先表示反之
> 反射表示：高位优先表示的反射表示为低位优先表示，低位优先表示的反射表示为高位优先表示

这相当于一个映射：

$$
BinToPoly:a_{n}\cdot 2^n + a_{{n-1}}\cdot 2^{n-1} + \dots +a_{1}\cdot 2 + a_{0} \mapsto a_{n}\cdot x^n + a_{{n-1}}\cdot x^{n-1} + \dots +a_{1}\cdot x + a_{0}
$$

例如数据 `1101` ，看作多项式应为

$$
M(x) = x^3+x^2+1
$$

令生成多项式 `1011` 为

$$
G(x) = x^3 + x + 1
$$

CRC 位宽为 $W=\deg(G)$ ，即 $W=3$ 。

计算

$$
R(x) = M(x)x^W \mod G(x)
$$

其中 $\deg(R) < W$ 。
$M(x)x^W$ 就是把数据左移 $W$ 位，也就是后面补 $W$ 个0。

最终发送的结果为

$$
T(x) = M(x)x^W + R(x)
$$

由于第一项为左移 $W$ 的结果，第二项位宽为 $W$ ，故两项可以直接被接收方分离从而获得原数据 $M(x)$ 。

# 校验过程

## 没有错误的情况

$$
T(x) = M(x)x^W + R(x) \\
$$

$R(x)$ 是 $M(x)x^W$ 模 $G(x)$ 的余数，可以表示为

$$
M(x)x^W = Q(x)G(x) + R(x)
$$

在 $\text{GF} (2)$ 中，无论 $R(x)$

$$
\begin{aligned}
T(x) & = M(x)x^W + R(x) \\
     & = Q(x)G(x) + R(x) + R(x)  \\
	 & = Q(x)G(x)
\end{aligned}
$$

故 $T(x) \mod G(x) \equiv 0$，注意，$\text{GF}(2)$ 中每个元素（1或0）的逆元是它自身，于是 $R(x) + R(x) = 0$ 。

也就是说，如果 $T(x)$ 在传输过程中没有错误，没有被篡改，那么，接收方对 $T(x)$ 取模就等于 $0$ 。

## 有错误的情况

任何传输中 $T(x)$ 的位错误，都可以由加上一个错误多项式得到，这是 $\text{GF}(2)$ 的逆元存在性质保证的。设错误多项式为 $E(x)$

$$
T'(x) = T(x) + E(x)
$$

有

$$
T'(x) = Q(x)G(x) + E(x)
$$

如果，$E(x)$ 不为 $G(x)$ 的倍数，那么接收方对 $T'(x)$ 的模就不为 $0$ ,可以判定数据一定错误。注意到如果接收方取模得到的数为 $0$ 并不意味着数据一定正确，因为如果错误多项式为生成多项式的倍数，那么结果也为 $0$ 。为了使校验囊括更多的错误情况，生成多项式的设计目标是保证常见的错误不是 $G(x)$ 的倍数。一般来说，生成多项式的常数项为 1 ，这可以保证单比特错误被检查出来。

# 代码实现

$$
R(x) = M(x)x^W \mod G(x)
$$

$$
T(x) = M(x)x^W + R(x) \\
$$

我们需要考查 $\text{GF}(2)$  中运算的程序实现方法。加法运算和乘法运算都已经被定义，减法和除法运算由逆元给出。我们已经知道 $M(x)x^W$ 代表 $M(x)$ 向高位移位 $W$ ，而对于取模运算，我们求**多项式的竖式除法**。

## 取模运算（归约）

取高位优先标准，假设被除数为 `11010000` ，除数为 `10011` 。

```
M(x)·x^4 = 1101 0000
初始状态
  1101 0000
  0001 0011
  
第 1 步：除数左移 3 位，除数最高位对应被除数位为 1, 归约
  1101 0000
^ 1001 1000      (10011 << 3)
-----------
  0100 1000
  
第 2 步：除数左移 2 位，除数最高位对应被除数位为 1, 归约
  0100 1000
^ 0100 1100      (10011 << 2)
-----------
  0000 0100
  
第 3 步：除数左移 1 位，除数最高位对应被除数位为 0, 跳过
  0000 0100
^ 0010 0110      (10011 << 1)
-----------
  0000 0100
  
第 3 步：除数左移 0 位，除数最高位对应被除数位为 0, 跳过
  0000 0100
^ 0010 0110      (10011 << 0)
-----------
  0000 0100

余数 = 0100
```

与整数除法不同，整数减法有借位，但多项式减法是对应项上的数相减，相当于向量相减，这里就是即按位异或。

注意到左移次数最多是 $\deg (被除数) - \deg (除数)$ ，这就是单次归约需要的计算次数。

## 具体实现

```c
unsigned long crc32(unsigned long crc, const uint8_t *ptr, size_t buf_len)
```

设一次处理 $8$ 位数据，`crc` 变量的含义是上次计算得到的 $R_{0}(x)$ ，`ptr` 为追加计算的数据块， `buf_len` 是数据块的总数。算法返回加入所有数据块后得到的新 $R_{1}(x)$ 。也就是说，当一段数据的 $R(x)$ 计算完成后，将 先取高位优先标准，推导分批加入数据的 $R(x)$ 如何计算，同时理解为什么 CRC 可以分批计算。

令上一次计算得到的余数结果为 $R_{0}(x) = (M_{0}(x)x^{32})\mod G(x)$ ，这一次加入的八位数据为 $M_1(x)$ 。那么这一次计算用到的 $M(x)$ 应为

$$
M(x) = M_{0}(x)x^{8} + M_{1}(x)
$$

那么 $R(x)$ 应为

$$
R(x) = (M_{0}(x)x^8 + M_{1}(x))x^{32} \mod G(x) = (M_{0}(x)x^{40}+M_{1}(x)x^{32})\mod G(x)
$$

对于同一个模数，在取模前对其部分取模于结果无影响，对第一项取模

$$
\begin{aligned}
M_{0}(x)x^{40}\mod G(x)&=M_{0}(x)x^{32}x^8\mod G(x) \\
&=(M_{0}(x)x^{32}\mod G(x)(x^8\mod G(x)) \mod G(x) \\
&=R_{0}(x)x^8 \mod G(x)
\end{aligned}
$$

由于 $x^8$ 的度小于 $G(x)$ ，取模后保持不变。

最后， $R(x)$ 为

$$
R(x) = R_{0}(x)x^8+M_{1}(x)x^{32}
$$

$$
\boxed{R(x) = (R_{0}(x) + M_{1}(x)x^{24})x^8\mod G(x)}
$$

我们就是要用这个公式计算在之前计算 $M_{0}(x)$ 的基础上，向后追加数据 $M_{1}(x)$ 后的 CRC校验余数。

### 高位优先的一次性移位后统一归约的实现

```c
#include <stdint.h>

uint32_t crc32_msb_update_byte(uint32_t remainder, uint8_t byte)
{
    /* 完整生成多项式，包含 x^32 项，需要 33 位。 */
    const uint64_t polynomial = UINT64_C(0x104C11DB7);
    uint32_t mixed;
    uint64_t dividend;
    int bit;

    mixed = remainder ^ ((uint32_t)byte << 24);

    /* 左移 8 位，完整保留最多 40 位的结果。 */
    dividend = (uint64_t)mixed << 8;

    /* 多项式取模运算：对次数 39 到 32 的项逐一归约。 */
    for (bit = 39; bit >= 32; --bit)
    {
        if (dividend & (UINT64_C(1) << bit))
            dividend ^= polynomial << (bit - 32);
    }

    /* 所有次数 >= 32 的项都已消除，此时转换不会丢失有效位。 */
    return (uint32_t)dividend;
}
```

其中 `0x104C11DB7` 为 IEEE CRC32 标准下的生成多项式。其中归约的方法就是多项式竖式计算的传统方法。

令 $B(x) = R_{0}(x) + M_{1}(x)x^{24}$ ，定义函数 $S(B(x)) = B(x)x \mod G(x)$ 。

$$
\begin{aligned}
R(x) & = (R_{0}(x) + M_{1}(x)x^{24})x^8\mod G(x) \\
	 & = B(x)x^8 \mod G(x) \\
	 & = \dots((B(x)x)\mod G(x))x \mod G(x)\dots \\
	 & = S^8(B(x))

\end{aligned}
$$

$B(x)$ 的位宽为 $32$ ，在这个算法中，$S(B(x))$ 在每一步都是对一个 $32$ 位的数据 $B(x)$ 进行计算，而一次性移 $8$ 位，再统一取模数的算法每次对一个 $32 + 8=40$ 位的数据进行计算。这种逐位归约的算法是对上一种算法的一个优化，节约空间，存储从 $40$ 降到 $32$ 位。

### 逐位优化实现

逐位优化的算法代码如下：

```c
#include <stdint.h>

uint32_t crc32_msb_update_byte(uint32_t remainder, uint8_t byte)
{
    uint32_t reg = remainder ^ ((uint32_t)byte << 24);
    unsigned int bit;

    for (bit = 0; bit < 8; ++bit)
    {
        if (reg & UINT32_C(0x80000000))
            reg = (reg << 1) ^ UINT32_C(0x04C11DB7);
        else
            reg <<= 1;
    }

    return reg;
}
```

由于生成多项式最高项为 `1`，而此时被除数最高项也为 `1, 1 ^ 1 = 0` ，故生成多项式省略最高项，同时用 $B(x)x$ 移位直接将被除数最高位移除，其余各位正常按异或归约。

### 低位优先的逐位优化实现

低位优先的逐位优化实现代码如下：

```c
unsigned long crc32(unsigned long crc, const uint8_t *ptr, size_t buf_len)
{
	uint32_t reg = (uint32_t)crc; 
    const uint8_t *p = (const uint8_t *)ptr;
	unsigned int bit;
	while(buf_len)
	{
		reg ^= *p++;
		for (bit = 0; bit < 8; ++bit)
		{
			if (reg & 1u)
				reg = (reg >> 1) ^ 0xEDB88320u; // reg >> 1 处理G（X）省略常数项
			else
				reg >>= 1;
		}
	    --buf_len;
	}
    return reg;
}
```

其中生成多项式为反射后的省略最高次项原生成多项式 `0x04C11DB7`，以适应低位优先的规定。
